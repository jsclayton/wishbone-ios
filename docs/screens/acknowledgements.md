# Acknowledgements

## Purpose

The license notices that the app must show: its own, and those of the packages it ships. The rules are in the spec: [Source code and Acknowledgements](../spec.md#source-code-and-acknowledgements).

## How you get here, and where you go

**Pushed** from **Acknowledgements**, in the About section of [Settings](settings.md). It opens nothing.

## Content

1. The app's MPL-2.0 notice.
2. The full license text of each package that the app ships, under the package's name.

**Provisional.** Plain default: a plain scrolling text screen, with a heading for each package.

## States

One state. The text is in the app, so the screen needs no connection.

## Windows

The text keeps a readable width in a wide window.

## Actions

None. The text can be selected and copied.

## Words

The title "Acknowledgements" is decided. The notices are the licenses' own words, and are not translated.

**Provisional.** The line above the packages is a draft: "Wishbone uses these open source packages."

## Accessibility

- The text scales to the largest sizes, and wraps.
- Each package's name is a heading, so VoiceOver can go from one to the next.

## Secrecy

None.
